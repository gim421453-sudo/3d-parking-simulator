### 나선 램프 원인 분석 (물리 / 치수 / 시험 구분)
- 측정: 대형 SUV(길이 4.94, 폭 2.00, 축거 2.97, 최대 조향 0.62rad). 정상 원선회에서 차체가 쓰는 환형 = 안쪽 `R−1.0`, 바깥 `√((R+1.0)²+3.84²)`.
- **이전 타워 나선(r 3.4~7.0, 폭 3.6m)**: 통과 가능한 뒷축 반경은 기하상 4.40~4.85m. 그런데 **이전 조향식**은 2m/s 에서 이미 조향이 8% 줄어 최소 반경이 4.60m → 실제 여유 **0.25m**. → *치수(임시 배치) + 조향식* 문제. 충돌 판정/서브스텝/FPS 문제가 아니다.
- 수정 ①(물리): 9km/h(2.5m/s) 이하 **풀 조향**(`maxSteerAt`). 실차와 같다. ②(임시 배치 치수): 타워 나선 **r 2.8~7.3, 폭 4.5m**(중심 그대로) → 여유 1.05m. `spiral` 맵(r 4.2~9.2)은 원래 여유 2.2m 라 변경 없음.
- 검증: 헤드리스 108회(SUV/세단/쿠페 × 1.5~3.5m/s × 경로 반경 3 × 횡오프셋 3) 충돌 0 · 하강 · 커브 중 제동/재출발 · 후진 하강 · 브라우저 3회(SUV 2/3m/s, 세단 2.5m/s). 기존 E2E 속도는 2.0m/s 로 복원.
- 시험(오토파일럿) 쪽: 후진 추종은 주시 거리 ≤2.2m 에서 조향이 진동해 안쪽 벽에 닿는다 — 자동 조종기 특성(주시 3m 이상에서 5개 조합 통과).

## 2. megapark (Gate 2)
- 9개 구역 유지(개별 맵도 그대로). **지하주차장 = 실제 B1 (y=−3.2m)**: 동쪽 간선도로 → 진입로 → 경사로(길이 32m, 완화 6m, 최대 12.3%, 폭 7m 양방향) → B1. 지면 데크/지면 메시에 같은 트렌치 구멍, 양옆 옹벽(실제 충돌체), 지붕 슬래브(천장 2.9m), 실내 구역 조명(주변광 감소 + 자동 전조등).
  - 변경 전후: 이전 = 지상(y=0)에 실내형 + 북쪽 우회로로 동쪽 진입 / 이후 = 지하 B1, 동쪽 벽 개구부(폭 7m)만 열림. 내부 치수·장애물·미션은 그대로.
- 도로망: 서쪽 간선(기존) + **동쪽 간선(x=80)** + 구역 사이 **연결도로 10개** → 격자형 순환. 양방향 2차로, 중앙 점선/가장자리선, 보행로, 구역 진입로, 기계식 대기 공간. 경계 `maxX 70 → 95`.
- 미구현: 도로 표지판, 커브(곡선 도로) — 현재 교차로는 직각.

## 3. 다층 도로 그래프 / 내비 (Gate 2)
- `nav/levelGraph.ts`: 데크 격자 노드(지상 3m, 그 밖 2m) + 경사로 중심선(양 끝 직선 연장 = 정렬 진입) + 나선 중심 반경선. 간선은 0.5m 표본으로 지면 연속/충돌체/천장을 검사 → **지상에서 지하 칸으로 곧장 가는 가짜 간선 없음**.
- 차종: 차폭(여유 0.7→0.5→0.35 순으로 시도) · 차고(천장) · 나선 통과 반경. 도로 우선(0.6) · 포장면 1 · 잔디 8. 일방통행(`RoadSeg.oneway`) 지원(현재 맵은 모두 양방향).
- A*(이진 힙). megapark 그래프 약 1만 노드, **첫 생성 0.8~1.8초(프레임 멈칫 가능 — 미해결)**, 경로 탐색 1~13ms.
- 내비 상태: 현재 층/목적지 층, 경사로 방향과 도착 층("경사로 내려가기 → 지하주차장 B1"), 같은 층에서만 도착 처리.
- 부분 완료: megapark **구역 내부** 미션 경로 102건 중 33건은 헤드리스 자동 주행으로 끝까지 가지 못했다(경사로 끝 급회전/주차 기동 — 자동 조종기 한계인지 경로 문제인지 건별로 가리지 못함). 경로 자체의 유효성(지면 위·벽 미관통·층 점프 없음)은 전부 검사.

## 4. 대형 월드 (Gate 3)
- `world/tiles.ts`: `WorldGrid`(타일 좌표) · `TileStreamer`(로드/언로드 히스테리시스) · `FloatingOrigin`(렌더 원점 이동, 전역 좌표 불변) — **순수 로직 + 단위 테스트**. 플로팅 오리진은 **렌더러에 아직 연결하지 않았다**(megapark ±300m 에서는 불필요).
- megapark: 고정 구조물 메시를 48m 타일 그룹으로 묶고 화질별 반경(낮음 90 / 보통 130 / 높음 180m) 밖은 숨김, 안개 끝을 반경에 맞춤. 논리 상태(시설/보관 차량)는 타일과 무관.
- 도시 키트 `world/cityKit.ts`: 도로/교차로/상업·주거/주차장/골목/기계식 블록 모듈 → `citytest`(3×2 블록, 임시). **실제 도시를 재현한 것이 아니다.**
- 미구현: 텍스처 지연 로딩, 원거리 LOD 프록시, GPU 자원의 타일 단위 해제(지금은 숨김만).

## 5. 시설/신규 맵 (Gate 4) — 모두 임시 배치(치수 확정 전)
- 기계식: megapark 원점 12층 + 야외 북쪽 6층 **실제 입고**와 시설 독립(브라우저). 미설치 맵(lot/modlot/underground/tower/garage5/carpark3/spiral) 추가 배치는 **하지 않았다** — 기존 배치를 바꾸거나 외부 연결 구역을 새로 만들어야 해서 위치 결정이 필요.
- 정비소 `garage`: 건물 24×14m(지붕 생략), 문 2개(4m), 2주식 리프트(`service/lift.ts`: 정위치·P·주차브레이크·시동 OFF → 암 고정 → 상승 1.8m → 정지 → 하강 → 고정 해제). PageUp/PageDown/End + 패널. **미션 모드에서는 정차 즉시 결과 화면으로 끝나 리프트를 끝까지 쓸 수 없다(자유주행에서만)** — 미션 성공 조건 변경은 결정 필요.
- 골목길 `alley`: 폭 3.4~3.6m, 직각 2회, 평행주차 홈, 막다른 골목 + 회차 공간, 입구/모서리 가각 2.5m. 차종별 통과: 소형/세단 전진만으로 전 구간, SUV·쿠페 꺾어 넣기 ≤2회, **차폭 2.34m 컨셉 쿠페는 통과 불가**.

## 6. 맵 자동 검사 (`tests/mapAudit.test.ts`, 모든 맵)
