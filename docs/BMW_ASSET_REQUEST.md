## 받는 방법 (본인 브라우저에서, 비밀번호/쿠키/토큰을 채팅에 붙여 넣지 마세요)
1. Sketchfab 에 로그인한다(계정은 본인만 사용).
2. 모델 페이지 `https://sketchfab.com/3d-models/<모델 ID>` 로 이동 → **Download 3D Model** → **glTF** 또는 **GLB**(없으면 원본 형식)를 고른다.
3. **라이선스 화면을 캡처**하고(다운로드 팝업의 License 문구 + 모델 페이지의 제작자/링크), 모델 페이지 주소와 제작자 이름을 적어 둔다.
4. 파일을 저장소 **밖** 폴더에 둔다 — 예: `C:\dev\_incoming\bmw\` (Git 에 올리지 않는다).
5. 채팅에 파일 경로와 라이선스 캡처(이미지)만 알려 준다.

## 파일을 받은 뒤 진행할 작업 (순서)
1. 원본 보존(`_incoming` 은 수정하지 않음) → 폴리곤/재질/크기 분석.
2. Blender 후처리: 단위/원점(뒷축 중심 기준 정렬), 실제 제원(`VehicleSpec`)에 맞춘 스케일, 바퀴 4개 분리 + 회전/조향 피벗, 실내 분리, 램프(헤드/테일/방향지시) 발광 재질 분리, 모바일용 LOD(삼각형 수 상한), 텍스처 압축.
3. 게임 연결: 시각 모델만 교체한다 — **충돌체/센서/카메라 좌표는 `VehicleSpec` 이 가진 값 그대로**(시각 모델을 바꿔도 충돌·센서·판정이 변하면 안 되는 규칙).
4. 주행/PDC/카메라 시험 + 모바일 성능 측정.
5. **저장소 반입 전 라이선스/상표 확인**: CC BY 는 제작자 표기 필수(`public/models/LICENSE-*.md` + `docs/ASSETS.md`). BMW 는 상표이므로 **공개 저장소/배포에 포함할지는 사용자가 결정**한다(비공개 보관만 할 수도 있다).
