# v0.4 구현 요약 (전자식 레버 · 공유 인포테인먼트 · 3D 시점 · 내비게이션)

| 영역 | 파일 | 핵심 규칙 |
|---|---|---|
| 변속 인터록 | `src/vehicle/transmission.ts` | P 이탈·N→R/D·D↔R 은 브레이크 필수, →P 는 정지 부근, →R 은 전진 저속, →D 는 후진 저속, →N 항상 허용. 거부 시 한국어 사유. 키보드/게임패드/레버가 `Game.requestShift` 한 경로 |
| 기어박스 분리 | 같은 파일 `Gearbox`, `gearboxFor` | 자동만 구현. **수동 변속기는 스텁(`implemented:false`)** — 물리 미구현 |
| 전자식 레버 | `src/ui/shifter.ts` | 세로 드래그, 놓은 위치의 노치로 변속, 첫 포인터만, pointercancel/blur/화면 밖 안전, 불가 노치 어둡게 |
| 게임패드 | `src/game/gamepad.ts` | 순수 매핑(`mapGamepad`). D-pad 상/하 = 기어 한 단계 |
| 인포테인먼트 | `src/infotainment/controller.ts` | 한 상태(표시/내용/수동 override). 3인칭 플로팅 = DOM, 1인칭 = 실내 캔버스 텍스처(`cabinScreens.ts`) |
| 자동 전환 | `src/pdc/assistPolicy.ts` | R: 후방+PDC, D 저속: 전방+PDC, D 15km/h 초과: 내비게이션. 최소 유지시간+히스테리시스. 우선순위: 수동 카메라 > 표시 토글 > 자동 |
| 3D 시점 | `src/pdc/viewPolicy.ts`, `game/cameras.ts` | 실제 센서 방향/단계로 좌/우/탑/사선 선택, 해제 후 복귀, 쿨다운. 센서 PDC 탑뷰는 그대로 |
| 내비게이션 | `src/nav/*` | 맵 충돌체에서 도로 그래프 자동 생성, 다익스트라, 재탐색, 도착 판정. 거리(m)는 내비 콘텐츠 안에서만 표시 |
| 미러/실내 | `src/game/mirrors.ts`, `vehicle/carModel.ts` | 사이드/룸미러는 실제 장면 렌더(FPS 설정), 센터/클러스터 캔버스 |
| GLB 시험 | `public/models/sedan-test.glb`, `scripts/make-test-glb.cjs` | 자체 절차 모델을 내보낸 파일로 로더만 검증. 고품질 외부 모델 아님 |

## 설정 변경
- `assistFrontMaxKmh` 기본 15 (이전에 저장된 값은 유지됨).
- 신규: `assistAutoView`, `infoAutoShow`, `infoAutoHide`, `infoAutoHideSec`, `cabinFps`, `mirrorFps`.

## 차량 데이터 분리
`VehicleSpec` 에 `transmission`, `category` 추가(`export:data` 반영). 수동/SUV/버스/트럭은 필드만 준비, 구현 안 됨.

## BMW 에셋 조사 결과
라이선스·재배포가 확인된 BMW 차량 모델을 찾지 못해 **도입하지 않음**(추출 모델/불명 라이선스/상표 문제). 대안: 자체 절차 모델 유지, `docs/FREE_ASSETS_SURVEY.md` 의 CC0/CC-BY 후보 중 직접 확인 후 도입.

## 미구현 / 한계
- 수동 변속기 물리, 서라운드(360° 합성)는 없음 — 3D 시점은 가상 카메라 렌더이며 합성 영상이 아님.
- Blender 미설치 환경 → 실제 Blender 편집 GLB 없음(절차는 `docs/BLENDER_PIPELINE.md`).
- 모든 검증은 소프트웨어 WebGL 헤드리스. 실기기 FPS/터치감/미러 성능은 **미검증**.
- Pages 배포 미실행(아래 HANDOFF 참고), v0.4 APK 미빌드.
