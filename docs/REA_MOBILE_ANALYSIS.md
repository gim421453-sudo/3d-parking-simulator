# 모바일 운전게임 기술 분석 (v0.6.3, P2) — REA 준비 상태와 비교

> **요약: 이번 작업에서는 대상 앱의 APK·실행 기기를 확보하지 못해 내부 코드 분석과 게임플레이 측정을 하지 않았다.**

## 2. REA (https://github.com/morluto/rea)
- 정체: AI 에이전트용 리버스 엔지니어링 MCP 서버. 분석은 로컬에서 실행된다. npm 패키지 `rea-agents`(이 세션에서 `npm view` 로 확인: 6.9.0, 저장소 `github.com/morluto/rea`, MIT, Node `^22.23.4 || ^24.22.1 || >=26.12.1`).
- APK 분석: Manifest·클래스·디컴파일 메서드·참조. **headless JADX + JDK** 가 필요하다. 기기 작업용 **ADB 는 사용자가 따로 준비**하고, 리소스 분석에는 **Apktool** 이 필요하다.
- IL2CPP: 메타데이터 v24/27/29/31/39 정적 디코딩을 내장한다(Unity 설치 불필요). README 에 "Unity" 가 대상으로 따로 적혀 있지는 않다.
- 사용 조건: README 에 "합법적 연구·교육·상호운용·보존, 소유하거나 분석 권한이 있는 소프트웨어"용이라고 되어 있다. 상용 도구 라이선스는 제공하지 않는다.
- 저장소 경고: "비슷한 저장소 이름이나 복사한 README 는 공식 배포를 뜻하지 않는다" → 공식 npm `rea-agents` 와 공식 저장소만 쓸 것.
- **설치·연결 여부: 하지 않았다.**
  - 이 작업은 클라우드 컨테이너에서 했고, 사용자 Windows PC 는 연결되어 있지 않았다.
  - `rea setup` 은 MCP 설정을 바꿀 수 있어서, 사용자 PC 의 Claude Code/Codex 설정을 백업한 뒤 사용자가 직접 실행하는 것이 맞다.
  - APK/ADB 작업은 사용자 지시로 보류 중이다.

### Windows PC 준비 절차 (사용자가 직접 — 아직 실행 안 함)
1. Claude/Codex 설정 백업. 파일 복사가 아니라 Git 저장소 밖 설정이므로 백업 폴더로 복사한다.
   - `%USERPROFILE%\.claude.json`, `%USERPROFILE%\.claude\settings.json`, `%USERPROFILE%\.codex\config.toml`
2. 버전 확인. Node 가 22.23.4 미만이면 업데이트한다.
   ```powershell
   node -v; npm -v; java -version; adb version
   ```
3. JADX(공식 GitHub 릴리스 skylot/jadx)와 JDK 17 이상을 설치한다. Apktool 은 리소스가 필요할 때만 설치한다.
4. REA 설정. 무엇을 바꾸는지 출력을 읽고 승인한다.
   ```powershell
   npx rea-agents setup
   ```
5. 분석 대상은 **본인 기기에 정상 설치된 앱에서 본인이 추출한 APK** 로 한다. 이용약관에서 리버스 엔지니어링을 금지하는지 먼저 확인한다.

## 5. 우리 게임에 적용할 만한 기술 (일반적인 모바일 운전게임 기법 — 위 앱에서 확인한 것이 아님)
| 기술 | 기대 효과 | 난이도 | 비고 |
|---|---|---|---|
| 속도 감응 조향비(고속에서 핸들 민감도 감소) | 고속 안정 | 낮음 | `maxSteerAt` 에 이미 일부 있음 — 곡선 조정만 |
| 터치 핸들 관성/자동 복귀 곡선 조정 | 모바일 조작감 | 낮음 | 실기기 손맛 테스트 필요 |
| 기울기(자이로) 조향 옵션 | 한 손 조작 | 중간 | 권한·보정 UI 필요 |
| 차체 롤·피치 시각 연출(서스펜션 근사) | 주행감 | 중간 | 시각만, 충돌 상자 불변 규칙 유지 |
| 정적 배칭/LOD 3단계 + 그림자 거리 제한 | 모바일 FPS | 중간 | 사하구 타일에 먼 거리 LOD 추가 |
| 면허시험 코스형 미션(T자·S자·경사로 정지) | 콘텐츠 | 중간 | 맵 치수 확정 후 고정 제작 규칙 |

**다음 단계(사용자 필요)**
- 대상 앱의 정확한 패키지명·버전을 확인한다.
- 본인이 추출한 APK 를 준비한다.
- PC 에서 REA 설정을 승인한다(또는 이 세션에 PC 를 연결한다).
- 블랙박스 측정은 화면 녹화 영상만 있어도 할 수 있다. 회전반경·핸들 복귀 시간·제동거리를 프레임 단위로 잰다.
