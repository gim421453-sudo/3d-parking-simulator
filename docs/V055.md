## 조건 완화 (#2) — Claude 가 정한 해석, 되돌리기 쉬움

사용자는 "조건 완화"만 지정했다. 다음과 같이 풀었다. 다르게 원하면 숫자/항목만 바꾸면 된다.

- **시동 끄기** (`vehicle/engine.ts` `pressStartStop`): 이전 = 정차 + P/N. 지금 = **정차만**. D/R 에서 끄면 P 로 자동 변속(`autoPark`, Game 이 `shiftGear(car,'P',true)` 호출). 주행 중에는 여전히 거부. 시동 **걸기** 조건(정차 + P/N + 브레이크)은 그대로.
- **리프트 상승** (`service/lift.ts` `liftChecklist`): 주차 브레이크·시동 OFF 를 필수 조건에서 제거(고정된 동안 주차 브레이크는 자동). 허용치 좌우 ±15→25cm, 앞뒤 ±30→45cm, 방향 ±4→6°. 남은 조건: 차폭/정위치/방향/정차/P 단.
- 기계식 입고의 "시동 OFF" 조건은 바꾸지 않았다(요청 범위 밖).

## 모든 맵 기계식 주차장 (#6)

- `withMechAnnex(map, opts)`: 맵 경계 한쪽에 마당(깊이 27m × 폭 22m, **임시 치수**)을 붙이고, 그 자리의 지상 벽을 폭 6m 로 잘라 문을 낸다. 마당 3면에 외벽, 시설은 `facilityKit` 그대로(진입 방향이 바깥쪽). 입고 미션 `<맵id>-mech-in` 추가.
- **원본 맵은 바꾸지 않는다**: `BASE_MAPS`(원본) / `MAPS`(부속 구역 포함). megapark 합성은 원본 파일을 직접 쓰므로 영향 없음.
- 지형 맵은 마당 지면 데크를 추가(차량이 설 수 있어야 함). 실내 맵(지하주차장)은 `env.ceilingRect` 로 천장이 마당을 덮지 않게 했다.
- 문 위치는 `scripts/find-annex-sites.ts` 가 찾는다(문 자리에 벽만 있음 · 승강장까지 직선 통로가 비어 있음 · 시작 위치에서 기구학 경로 있음).

## 엔진음 재제작 (#8)

- 이전: 톱니파/사각파 발진기 3개 → 전자음 같은 소리.
- 지금 (`audio/engineSound.ts`): **소스-필터 모델**. ① 엔진 사이클(720°)마다 실린더 수만큼 폭발 펄스를 담은 버퍼(`enginePulseWave`, 8사이클, 결정적 난수)를 회전수에 비례한 속도로 재생 ② 실린더별 세기 차이 → 반차수 성분(낮게 깔리는 울림) ③ 저부하/고부하 두 파형을 스로틀로 섞음 ④ 비대칭 왜곡 → 고정 공명 필터(95/276/720Hz = 배기관·차체 울림, 회전수가 변해도 음색 유지) → 부하에 따라 밝아지는 고역 선반 필터 → 실내/실외 로우패스 ⑤ 흡기 소음, 공회전 떨림.
- 전부 코드 합성이며 실제 차량 녹음이 아니다.
- 검증: 단위 테스트(파형 주파수 성분) + `scripts/audio-v055.cjs`(OfflineAudioContext 로 실제 그래프를 렌더해 무음/클리핑/점화 주파수/실내 감쇠/부하 밝기 검사, 4개 엔진 × 5개 상태 ALL PASS).
- **한계: 헤드리스 환경이라 귀로 들어 보지 못했다.** 수치 검사는 "엔진 소리처럼 들리는지"를 보장하지 않는다. 직접 들어 보고 평가가 필요하다.

## 계기판 (#9)

`infotainment/cabinScreens.ts` `drawCluster`. 표시 값은 전부 실제 게임 상태(RPM 만 시뮬레이션 근사 — 화면에 표기).

- 바늘 게이지 2개, 속도 눈금 60 ↔ 차량 최고속도 자동 전환(`speedScale`, 히스테리시스), 엔진별 적색 구간
- 페달 입력 막대(B/A), 핸들 각도, **방향별 PDC 평면도(색만, 숫자 없음)**, 경사계(차체 피치: 평지/오르막/내리막)
- 엔진 상태(READY/시동 중/OFF), 엔진 이름, 시계, 층·미션(겹치지 않게 폭 계산)
- 경고등 줄: 조명 모드/상향/미등/P/제동/비상/PDC, 중앙 경고(장애물 근접 > 장치 고정 > 하차 중)
- 넣지 않은 것: 연료/수온/주행거리 — 해당 물리가 없어서 가짜 값이 된다.

## 4주식 리프트 (#10)
