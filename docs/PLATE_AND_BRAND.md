# 한국형 번호판 · 브랜드 마크 처리

## 번호판 (구현됨 — 임시 절차 차량 기준)
- `src/vehicle/plate.ts`: 520×110 mm 비율(4.7:1), 흰 바탕 + 좌측 파란 띠, 가상 번호 (M4 `123가 4567`, X6 `456나 7890`). 소유자와 무관한 임의 번호이며 사용자가 확정 전까지 임시.
- 앞/뒤 동일 텍스처, 재질명 `Plate_KR`, 노드 `Plate_Front/Rear` → GLB 교체 시 같은 이름으로 연결 가능.
- 번호 교체: `VehicleSpec.plate` 값만 변경(형식 검사 `isValidKrPlate`).
- **미구현**: 야간 후면 번호판 조명(번호판등) — 차량 점등 시스템에 `Lamp_Plate` 추가 필요(다음 단계).
- 국가 표기 영역은 상표/국장 이슈를 피하려 `KR` 문자만 사용.

## 브랜드 마크 정책 (계획)
- 공개 Pages 배포 전제: 제조사 로고는 **제거 상태**로 작업. 대상: 보닛/트렁크/휠캡/핸들 중앙/센터 디스플레이 시작 화면/트림 배지.
- 텍스처에 구워진 로고는 메시 삭제로 사라지지 않으므로 텍스처도 검사.
- 원본(로고 포함) 모델은 저장소 밖에 별도 보존.
- 게임 내 차량명은 중립 이름 사용 중(`스포츠 쿠페 (M4 계열)` 등). 공개 UI 에서 실존 차종명 사용은 별도 검토(현재 "계열" 표기는 내부 구분용이며 상표 검토 전).
- 로고 제거가 라이선스·상표·디자인권 문제를 모두 해결한다고 가정하지 않는다.
