# v0.5.3 — P0 재검증 · 시동/엔진음 · 고속 주행 · 기계식 시설 모듈화

> 구현됨 / 브라우저 검증됨 / 미검증 / 차단됨 을 구분해서 적는다. 최종 수치는 문서 맨 아래 "검증 결과".

## Gate A — P0 (입고 후 새 차량 자동 생성 금지, 볼라드)
- **배포본 vs 소스**: Pages 에 배포된 것은 `63fde2e`(v0.5.2, 핫픽스 이전). "입고 후 새 차가 자동으로 생긴다"는 관찰은 그 배포본 동작이다. 최신 소스(핫픽스 `871d050` 이후)는 자동 생성 경로가 없다. 배포는 사용자 승인 후에만 한다.
- **숨은 경로 발견/차단**: `resetCar()`(T 키/초기화 버튼)가 관찰 상태에서 보관 차량 모델을 시작 위치로 옮길 수 있었다 → 관찰 상태에서는 초기화 거부. `mechExit`(G)는 관찰 중 토스트만. 새 차량은 `mechNewCar`(I/버튼)로만 — `newCarCount` 로 검증(런마다 0 으로 초기화).
- **볼라드 이동**(실제 충돌체 + PDC 감지 유지): 유도선 `z=±1.15`(폭 0.1) 바로 바깥으로.
  | | 이전 | 이후 |
  | --- | --- | --- |
  | 1열 | (−9, ±1.9) | (−9.5, ±1.30) |
  | 2열 | (−11, ±2.5) | (−13.0, ±1.30) |
  유도선 바깥 가장자리와 볼라드 안쪽 면 간격 0. 통과 폭: 세단/SUV/컨셉 쿠페(2.34 m)는 통과, 2.45 m 차량은 막힘(단위 테스트). 정면 접촉 시 관통 없음·후진 이탈 가능은 브라우저 E2E.

## Gate B — 시동 / 엔진음 / 고속 주행 / 거울
- **시동 상태기계** `vehicle/engine.ts`: OFF → STARTING → RUNNING → STOPPING → OFF. 시동 조건: 정차·P/N·브레이크. 정지 조건: 정차·P/N. 사유 문구를 토스트로 표시. **OFF 에서는 가속/크리프 차단**(`VehicleInput.engineOn`).
- **조작**: `O` 키, 클러스터 `#actionbar` 의 전원 버튼(터치 포함, 상태 OFF/ON/···). 설정: `engineSound`, `engineVolume`, `engineStartOff`(시동 OFF 로 시작; 기본 꺼짐 = 시동 걸린 채 시작).
- **계기판**: RPM 은 엔진 상태기계 값(시뮬레이션 근사, 화면에 "RPM · 시뮬레이션"; OFF/STARTING 시 `ENGINE <상태>`).
- **기계식 연동**: 시동이 걸려 있으면 하차(G)·입고(J) 거부("시동 OFF" 체크리스트 항목). 출고 후 탑승해도 **자동 시동 없음**.
- **엔진음**(`audio/engineSound.ts`, Web Audio 합성): 기본 주파수 = rpm/60 × 실린더/2, 스로틀/RPM/상태/실내·실외/볼륨 연동, 시동 크랭킹 효과음, 차종 프로파일(세단/SUV/쿠페). **실제 BMW 등 차량 음원이 아니다.** 경고음(PDC)과 설정이 별개. 자동재생 정책: `startRun`/시동 버튼(사용자 조작)에서 `init`.
- **고속 주행**: 차종별 최고속도 130(해치) / 140(SUV) / 150(세단 등) / 180(쿠페) km/h, 후진 20 km/h. 속도 의존 저항, 속도에 따른 최대 조향각 감소. **적응형 서브스텝**: 한 스텝 이동량 ≤ 0.12 m(최대 8분할) — 50 m/s 에서도 0.3 m 벽 관통 없음(단위 + E2E 137 km/h 정면 충돌, 100 km/h 급제동). 저속 주차 조작감은 서브스텝 1 로 동일.
- **거울 FPS**: 설정 `mechMirrorFps`(0=자동): 높음 30 / 보통 24 / 낮음 16, 거울이 보일 때만 렌더, 목표 FPS 는 게임 시간 기준으로 측정(E2E, `scripts/perf-v053.cjs`). 부동소수 오차로 절반 FPS 가 되던 문제 수정.

## Gate C — 기계식 시설 모듈
- `mech/facility.ts`: `MechFacilityConfig {id, name, x, z, rotationY, floors, slotsPerFloor, entranceMode, capacity, enabled}` + 월드↔로컬 변환(`world = origin + Rψ·local`). 장치 로직(`machine.ts`)·모델(`mechBuilder.ts`)은 **시설 로컬 좌표**에서 동작, 월드에는 변환만 적용 → 절대좌표 `STATION` 의존 제거(로컬 상수로만 남음).
- 시설마다 독립: `MechController`(상태기계/슬롯/차량/셔터/승강기), 모델 그룹, 셔터 충돌체(`<id>:door`), 보관 차량 모델 키 `<시설>/<슬롯>`. 층수 가변(2~12), 슬롯은 `m.slots` 에만 존재.
- `maps/mechKit.ts`: 벽/기계실/가이드/볼라드/도색/바닥을 시설 변환으로 맵 데이터에 추가. 회전은 90° 배수.
- 현재 시설 선택: 사용 중(보관 관찰/동작 중/고정)이면 유지, 아니면 가장 가까운 시설(히스테리시스 3 m). 다른 시설은 `stepIdle` 로 독립 진행.
- **설치 위치**: `mechpark`(12층 1기, 원점) · `outdoor`(동쪽 12층 (41,−26) 회전 90° / 북쪽 6층 (5,16) 회전 90°) · `megapark`(위 3기, 평행이동+ID 네임스페이스).
- **설치하지 못한 맵과 이유**(`MapData.mechUnavailable`): lot(미션 동선과 겹침), modlot(정밀 연습장·동선), underground(천장 2.9 m), tower/garage5/carpark3(지상층을 데크/경사로가 덮음), spiral(나선 경사로가 지상 공간 점유). 12층 타워를 억지로 넣지 않았다. 탐색 도구 `scripts/find-facility-sites.ts`.
- **이용 정책**(`parking/availability.ts`, 순수 로직, 설정 `parkLowRatio` 기본 20%): 기계식은 항상 이용 가능(만차/고장/비상정지 제외, 작동 중은 "잠시 후"). 일반 칸 잔여율 > 20% → 둘 다, ≤ 20% → 기계식 우선 추천, 0 → 기계식 안내, 기계식도 만차 → 가장 가까운 다른 구역 안내. 구역별 독립(megapark). 표시: 일반 칸 잔여/기계식 잔여 요약 + 추천 문구(HUD 미션 패널), 거리 숫자 없음. 시설 입구는 목적지 순환(`infoDest`)에 포함 — **사용자가 고른 시설은 순위와 무관하게 안내**, 추천 시설이 목록 맨 앞. **경로**: 도로 그래프가 있는 맵(outdoor)에서만, 도로 노드가 입구 가까이에 있을 때만 경로를 그린다(없으면 "경로를 찾을 수 없습니다" — 경로를 지어내지 않음). 다층/통합 맵(megapark)은 도로 그래프 미지원이라 경로 안내가 없고 시설 이름/입구/잔여/상태만 표시.

## 테스트 인프라 메모
- 간헐 실패 "수동 카메라 선택(후방)" 원인: 게임 상태(`assistOut.camera`)는 바뀌었지만 패널 DOM 문구는 카메라 갱신 주기로 한 박자 늦게 바뀜(소프트웨어 WebGL) → DOM 도 게임 상태로 기다리도록 수정(검증 내용은 동일).
- 소프트웨어 WebGL 에서 거울 갱신율을 올린 뒤 게임 시간이 느려져 긴 대기(100 s+)를 2배로. 검증 항목은 줄이지 않음.
- E2E 헬퍼 `engineOff()/engineOn()`: 실제 입력 경로(브레이크 + KeyO)로 시동을 끄고/켠다.
