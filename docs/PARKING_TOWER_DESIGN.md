# 주차타워(다층·경사로·나선 램프) — 구현 설명 (v0.4.5)

**주의: 현재 맵(`src/maps/mapTower.ts`)은 "검증용 임시 고정 레이아웃"이다. 최종 확정 맵이 아니다.**
층수·통로 폭·주차칸 치수·차량 배치는 사용자가 확정한 뒤 `mapTower.ts` 의 상수만 바꿔 반영한다. 맵 데이터(지형·충돌체·슬롯·미션)와 3D 에셋(`towerBuilder.ts`)은 분리되어 있고, 게임 중 랜덤 생성/편집 기능은 없다.

## 구현된 엔진 확장 (실제 주행에 연결됨)
| 영역 | 구현 | 파일 |
|---|---|---|
| 지형 데이터 | `deck`(평평한 층, 구멍 가능) / `ramp`(직선 경사로) / `spiral`(나선, 각도에 선형 높이). 같은 (x,z) 의 여러 층 중 차량 높이 ±0.7m 안에서 **가장 높은 면**을 지면으로 선택(층 점프 방지, 경사로 시작부 이탈 방지) | `maps/terrain.ts` |
| 차량 상태 | `VehicleState.y / pitch / slope` 추가. 앞·뒤 차축 아래 지면 높이로 y 와 pitch 계산, 올라설 면이 없으면 이동 불가(충돌처럼 복원) | `vehicle/physics.ts`, `Game.physicsStep` |
| 경사 물리 | 진행 방향 중력 성분 `-g·sinθ`. 풋브레이크/주차브레이크/P 는 경사에서도 정지 유지, N 은 굴러 내려감, D 가속으로 재출발 | `stepVehicle` |
| 층별 충돌 | 충돌체의 높이 구간 `[y0, y0+h]` 가 차량 높이 구간 `[y+지상고, y+차고]` 와 겹칠 때만 충돌. 다른 층의 같은 평면 좌표 물체는 무시 | `core/geometry.ts` |
| 층별 센서/PDC | 센서 레이 높이 = `y + 0.55`. 위·아래 층 차량을 감지하지 않음 | `sensors/sensorSystem.ts` |
| 카메라 | 후방/전방/추적/운전석/미러/보조 3D·탑뷰 모두 차량 지면 높이 기준. 추적 카메라는 천장(위층 바닥 아랫면) 아래로 제한. 보조 카메라 패스에서는 현재 층보다 위의 슬래브를 숨겨 천장에 가리지 않음 | `game/cameras.ts`, `pdc/framing.ts`, `Game.renderAssist` |
| 주차 판정 | 슬롯 `y` 와 차량 `y` 차이 ≤ 0.6m 이어야 성공(`levelOk`). 1F 에서 2F 주차칸 평면 위치에 서도 성공 아님 | `mission/parking.ts` |
| UI | 현재 층 표시 `#floor-ind`(1F/2F/3F), 미니맵은 현재 층 물체만 표시하고 경사로를 안내 | `ui/hud.ts`, `ui/minimap.ts` |
| 3D 에셋 | 층 슬래브(구멍 포함), 직선 경사로, 나선 경사로, 상층 도색을 맵 데이터에서 생성 | `maps/towerBuilder.ts` |

## 임시 레이아웃 (검증용)
- 1F(y=0): 입구(서쪽) → **직선 경사로 R1**(길이 22m, 폭 3.8m, 경사 14.5%) / 주차칸 6+6, 통로 7.7m
- 2F(y=3.2): R1 도착 / 주차칸 6+6 / **나선 램프 S1** 시작(반경 3.4~7.0m, 270°, 경사 약 13%)
- 3F(y=6.4, 옥상 지붕 없음): S1 도착 / 주차칸 6+6
- 층고 3.2m, 난간 1.1m(1F 외벽 3m), 경사로·나선 난간은 경사를 따라 올라가는 계단식 벽 조각
- 미션(임시): `tw-1` 1F 후진 주차, `tw-2` 경사로 상승 후 2F 전면 주차, `tw-3` 2F 에서 나선 램프 상승 후 3F 후진 주차

## 검증
- `tests/tower.test.ts`: 지형/높이/천장, 경사로·나선 **순수 추종 주행 시뮬레이션**(X6/세단/소형이 충돌·이탈 없이 2F/3F 도달), 경사 정지·재출발·제동, 난간 이탈 방지, 층별 충돌·센서 분리, 층 조건 주차 판정
- E2E: 실제 게임 루프에서 자동 주행으로 경사로 → 2F → 나선 → 3F, 층 표시, 센서, 주차 판정, 반복 시작 자원 안정

## 알려진 한계 / 미구현
- 내비게이션: 다층 맵은 층 이동 경로 계산 미지원(`noRoute` 로 명시). 층별 그래프 + 램프 간선 필요.
- 차체 롤/서스펜션 없음(피치만), 경사로 위 타이어 접지/미끄러짐 없음(정지 마찰은 완전 정지로 단순화).
- 2F/3F 슬래브 아랫면과 경사로 머리 충돌(천장 충돌)은 구현하지 않음(검증 레이아웃에서는 간섭 없음).
- 모바일 실기기 성능 미측정(헤드리스 소프트웨어 WebGL 만 확인). 층별 렌더 컬링은 보조 카메라 패스의 상층 슬래브 숨김만 구현.
- 사용자 확정 전 임시 배치이며 최종 맵이 아님.
