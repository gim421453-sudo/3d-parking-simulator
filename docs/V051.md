## 완료
- **기계식 입구 LED 표시기(전진/정지/후진)**: `machine.guidance()` — 앞바퀴 정지턱 거리·좌우 오프셋·헤딩으로만 결정(타이머 없음). 정렬 경고(좌/우 힌트), 문 닫힘/장치 동작 중 "진입 금지". 3D 표시판(CanvasTexture)이 입구 정면 문 위에 설치.
- **팔레트 정지 홈 안착**: 앞바퀴가 홈(깊이 3cm)을 지날 때 `MechController.settle` 가 높이/피치를 3cm 이내로 바꾸고(차량을 끌어당기지 않음), 속도 비례 충격 진동 + 합성 금속 효과음(`mech/sfx.ts`).
- **턴테이블 회전**: 출고 시 문이 닫히고 하차 상태일 때만 팔레트+차량이 180° 회전해 차량이 출입문을 향함. 승강장 안쪽 폭 6.6m. 회전 중 차량-팔레트 상대 위치 불변(단위 테스트), 비상정지/재개.
- **셔터**: 3D 롤업 문 + 닫히는 동안 동적 충돌체(`mech-door`) + 안전센서 인터록(기존).
- **금속 볼라드 4개**: 강철 원통 + 노랑 반사띠, 실제 충돌체(`bollard`) + PDC 감지(센서 높이보다 높음). 기존 콘 제거.
- **입구 가이드라인**: 중앙선, 좌/우 유도선, 전진 화살표, 문 앞 노란선 + 팔레트 중심선/정지 기준선(팔레트 모델).
- **전방카메라**: 범퍼 중앙(x=0), 차체별 튜닝(`FRONT_CAM_TUNE`, `scripts/tune-frontcam.cjs`). 자기 차체 가림 세단 51% → 12%. *E2E 의 높이 검사는 차체별 튜닝에 맞춰 "범퍼 윗면 +0.05~0.2m" 범위로 바꿨다(고정 +0.1m 에서 완화).*
- **경고 패널**: 높이 ≤0.5m(기본 0.42), 인접한 같은 단계 칸을 넓은 패널로 병합(넓은 벽 ≤4개), 센서 계산은 0.3m 칸 그대로. 앞 물체에 가려진 패널 제외. 전/후방 × 정중앙/좌우 끝/좌우 사선 10개 위치를 실제 센서로 단위 검증.
- **UI 겹침**: 6개 해상도(780×360, 800×360, 960×540, 1024×768, 1280×800, 1920×1080) × 3 컨텍스트(기계식/일반 3인칭/1인칭) 실제 렌더 DOM 겹침 0 (`scripts/ui-overlap.cjs`; 수정 전 4건 → 0). 기계식 패널을 우측 컬럼으로 옮기고 낮은 화면(≤420px)에서 미션/기계식 패널 축소.
- **E2E 실패 원인 수정**
  - 카메라 안정화(기준선에서도 실패): 후방 장애물 히트가 측면뷰 가림 판정·재래치에 섞여 시점이 풀리던 **실제 버그** → 측면 시점은 그 쪽 측면 히트만 사용(`sideFrameHits`). 테스트는 게임 상태(`assistSettled`) 대기로.
  - 기계식 입고 조건: 상태 갱신 전에 읽던 테스트 타이밍 → 갱신 대기.
  - 출고 미션: 테스트 브레이크 시점(제동거리 2.6m) 문제, 성공 조건은 그대로.
  - "후진" 표시기 E2E: 정지턱이 지나침을 물리적으로 막아 게임에서는 도달 불가 → 상태기계 단위 테스트로 검증(E2E 항목 삭제 — 약화가 아니라 검증 위치 이동, 본문에 명시).

## 부분 완료
- 서라운드(탑다운) 화면의 타이어 조향은 작아서 구분이 어렵다. 좌측 3D 뷰/모델 값(조향·4바퀴 회전·후진 역회전·정차 정지)은 확인. 카메라별 픽셀 단위 비교는 안 함.
- 경사 벽(oblique)은 패널이 여러 단계로 나뉜다(최대 9개, 표면 거리 차 0.3m 기준).
- 스크린샷 "회귀 검증"은 자동 골든 비교가 없다 — E2E 픽셀 단언 + 수동 확인(`docs/screenshots/v051/`).

## 미완료 / 차단
- **BMW M4 G82/X6**: Sketchfab 다운로드 API 가 로그인 없이 401. M4 모델은 CC-BY(작성자 Rosemarin, 104k 면)로 다운로드 가능 모델이지만 **인증 토큰이 필요**해 확보하지 못했다(우회 안 함). 토큰을 제공받으면 `scripts/prepare-car-glb.mjs` 로 가공해 적용 가능. 실차형 대체(컨셉 쿠페, BMW 아님)는 유지.
- 기계식: V홈 실제 규격, 사람 감지 시뮬레이션, 법규 인증 사양은 미구현/주장 안 함.
- 모바일 실기기 성능/터치/미러 FPS 미측정.
