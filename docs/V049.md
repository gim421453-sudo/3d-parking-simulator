- 전부 `terrain`(deck/ramp/spiral) + 충돌체 + 주차칸 + 스폰/미션을 **데이터로 직접 제작**했다. 외형은 기존 `towerBuilder`/`mapBuilder`(절차 생성)이며 **외부 GLB/SKP 를 사용하지 않는다**.
- 기존 4개 맵(`lot`, `underground`, `outdoor`, `tower`)은 그대로 유지, 맵 선택 화면에 총 8개.
- 도구: `maps/levelKit.ts`(층별 슬롯/기둥/외곽 벽/경사로 측벽/나선 난간/구멍 난간). 다층 맵 성능: `BuiltMap.setLevelVisibility`(현재 층에서 ±1.7m 밖 층의 주차 차량 모델 숨김), 목표 마커/빔이 슬롯의 층 높이 위에 놓이도록 수정(기존 타워도 3F 목표 마커가 바닥 아래였던 문제).
- 검증: `tests/{garage5,carpark3,modlot,spiral}.test.ts` — 순수 추종 주행 시뮬레이션으로 **X6·세단·소형 모두** 5층/3층/데크/나선 상층까지 충돌·지면 이탈 0회로 도달. 기존 `tests/maps.test.ts` 가 모든 차량 스폰/주차 가능성을 자동 검증.

## 2. PDC 센서 360° 보정
- 진단(`tests/sensorCoverage.test.ts`): 차체 둘레 0.5/1/2m 전체(0.2m 간격)에 0.15/0.3m 기둥을 세워 놓침을 센다. **보정 전**: 세단/SUV/M4/GLB 세단에서 전·후방 정중앙 0.5m 의 0.15m 기둥(안쪽 센서 사이), 코너 0.5m 일부에서 사각지대. **보정 후**: 모든 차량·모든 거리에서 0건.
- 변경: 안쪽 4개 센서 ±4° 토인 + FOV 66°, 바깥 코너 4개 센서 40° + FOV 90°. 센서는 여전히 12개(전4/후4/좌2/우2).
- 추가 검증: 옆 차량이 전/후방 위험으로 오분류되지 않음, 다른 층(±3m) 장애물 미검출, 낮은 연석(0.15m) 미검출은 정상·볼라드(0.9m) 검출, 제거 후 미감지 복귀.

## 3. 카메라 자동 전환 감소
- `pdc/viewGate.ts`(순수 로직): 장애물 "존재"와 "전환 필요"를 분리. 집중 탑뷰는 매우 가까운 장애물이 **예상 이동 경로**(`guideCutDistance`, 조향 반영) 위일 때만, 측면뷰는 그 쪽으로 조향(|steer|>0.1)하며 실제로 움직이고(|v|>0.3) 간격 <1.0m 일 때만.
- `ViewPolicy`: 확인 지연 0.3→0.5초, 최소 유지 1.4→2.2초, 쿨다운 0.9→1.8초.
- 효과(E2E): 양쪽 벽 0.45m 좁은 통로를 직진 통과하는 12초 동안 전환 0회(기존 정책은 측면/탑뷰로 반복 전환).
- 집중 탑뷰 자기 차량: 장애물 0.3/0.5/1/2/4/6m 모든 차량에서 범퍼 모서리·차체 40% 가 화면 안(`tests/focusTop.test.ts`).

## 4. 서라운드 = 흰색 선 정확히 2개
왼쪽/오른쪽 예상 이동 경계선만(굵기 1.8, 흰색). 눈금·화살표·경고선·차체 윤곽·점선·컬러 모두 제거. `AssistPanel.debugSurLines` 로 개수 검증. 센서 전용 화면은 컬러 PDC 유지.

## 5. 전/후방카메라에 실제 차체 표시
`spec.make` 가 카메라를 차체 윗면(벨트라인) 바로 위·가장자리 근처에 장착(`beltOf`), `assistCamera.near=0.03`, 전/후방 카메라 패스에서도 차체 메시를 그림(번호판은 숨김). 영상 하단 약 15~18% 에 **실제 범퍼 윗면 메시**가 보인다(2D 그림 아님). v0.4.7 의 차체 고정 카메라(보간 없음) 유지.

## 6. 디지털 계기판 (실내)
768×294 캔버스(0.44m 폭): 좌 속도계(0~60 눈금+디지털 속도), 우 회전계(**시뮬레이션 값**, 화면에 "RPM · 시뮬레이션" 표기), 중앙 기어(P R N D)·핸들 각도·층/미션, 상단 방향지시등, 하단 AUTO/하향/상향/주차브레이크/비상등/PDC 상태(색은 경고 단계만). `Game.lastClusterData` 로 실제 상태와 동기화 검증. 중앙 인포테인먼트와 가로 간격 ≥12px 유지(E2E).
