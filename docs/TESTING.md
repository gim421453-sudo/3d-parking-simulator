## v0.3 추가 테스트 (UI 재설계 / 필수 조작 접근성)

E2E 신규 32개 (기존 104개 전부 새 UI 에서 통과):
- **필수 운전 버튼 접근성**: 주차 보조가 열린 상태에서 방향지시(좌/우)·비상등·조명·주차브레이크·초기화 버튼이 `elementFromPoint` 로 실제 클릭 가능한지, 클릭 시 게임 상태가 바뀌는지 (PC + 모바일 터치 `tap`)
- **화면 크기별 겹침 검사 (7종 × 4항목 = 28개)**: 667×375, 800×360, 844×390, 960×540, 1024×600, 1280×720, 1920×1080 에서 주차 보조 패널이 화면 안에 있는지, 클러스터/아이콘바/미니맵/토스트/터치 버튼과 겹치지 않는지, 필수 조작 버튼 7개가 화면 안에서 가려지지 않는지, 사이드 버튼 높이 ≥ 36px
- 모바일(800×360 터치 에뮬레이션): 필수 버튼 터치 가능·동작, 사이드 버튼 ≥ 40px
- `npm run verify:pages`: 하위 경로 로드, 상대 경로, WebGL 삼각형 수, localStorage 유지, base 밖 요청 없음, 콘솔 오류 없음

테스트가 잡아낸 문제(수정함): 667×375 에서 토스트가 패널과 겹침 → 보조 화면 중 최근 토스트 1개만 표시·위치 조정 / 컴팩트 화면 패널이 아이콘바와 겹침 → 폭·위치 조정 / "카메라 화면" 라벨 줄바꿈 → 열 비율 조정.

## v0.2 추가 테스트 (feature/pdc-display-v2)

단위(`tests/pdc.test.ts` 27개, `tests/lighting.test.ts` 12개):
- PDC 구역이 센서 장착 방향과 같은 쪽에 있음(좌=+x, 앞=+z, 3개 차량 전부), 12구역이 360°를 빈틈없이 분할, 띠가 바깥→안쪽으로 채워짐, **미검출 구역 소등**, 뒤쪽 벽은 뒤 구역만/왼쪽 벽은 왼쪽 구역만 점등, 접근 단계 상승(far→mid→near→critical), 센서 OFF 시 소등, **상태 문구/모델에 거리 숫자 없음**, 팔레트 4색 구분.
- 가이드라인: 직진 평행선, 후진/전진 + 좌/우 조향 시 휘는 방향·대칭, **실제 `stepVehicle` 궤적과 일치**, 거리 구간 색.
- 표시 정책: R 자동 표시, R→D 에서 active 유지 + 카메라만 전방, D 고속 종료/히스테리시스 재표시, 속도 조건 설정, 자동 표시 OFF, P 지연 종료, N 유지/종료, 수동 카메라 우선·기어 변경 시 자동 복귀, 수동 닫기/열기.
- 조명: OFF/미등/하향등/상향등/AUTO 규칙(DRL 100%/30%), 순환 순서, AUTO Leveling 방향·데드밴드·±2° 제한·부드러운 수렴·진동 없음.

E2E(추가분): R 에서 패널 표시, **R→D 에서 같은 DOM 노드 + 패널/사이드 버튼 좌표 완전 일치 + 카메라만 전방**, D 고속 종료/저속 복귀, 수동 카메라 우선, P 지연 종료, B/닫기, **화면 어디에도 거리(m) 숫자 없음**, 디버그에서만 수치, 앞/좌/우 벽 → 점등 구역이 DOM 좌표상 올바른 방향, 장애물 없는 곳 전부 소등, 접근 단계(far→mid→near→critical), 센서 OFF "PDC 꺼짐", 가짜 360° UI 없음, 조향에 따라 가이드라인 좌/우 이동(캔버스 픽셀), 카메라 6종 순환, 조명 모드 순환/AUTO(지하 하향등), AUTO Leveling 가속/제동 방향, 모바일 패널 겹침 없음·사이드 버튼 ≥ 40px.

## 검증하지 못한 것 (PASS 로 표시하지 않음)

| 항목 | 이유 / 현재 상태 |
|---|---|
| **APK 설치/실행** | Actions 에서 APK 는 빌드됐지만(위 표) 실제 기기에 설치·실행해 보지 않음. 로컬 빌드는 개발 세션이 `dl.google.com` 을 차단해 불가 |
| 실기기 FPS/발열/터치감 | 휴대폰 없음. 헤드리스 값만 있음 |
| 경고음 실제 청취 | 헤드리스 환경. 간격 계산은 단위 테스트, WebAudio 생성은 오류 없이 동작하는 것만 확인 |
| 배포 환경 경로/리소스 로딩 | `vite preview`(정적 서버)와 상대 경로(`base: './'`) 빌드로 확인. **실제 GitHub Pages 하위 경로 배포는 미실행** |
| 오토 상향등 / AFS / 서라운드뷰 / 내비게이션 / 인터랙티브 실내·미러 | **미구현** (기능 없음 — 테스트 대상 아님) |
| 실제 휴대폰 UI 겹침/터치감 | ❌ **미검증** — 가상 뷰포트(667×375 ~ 1920×1080)와 터치 이벤트 에뮬레이션만 확인. 2026-11-03 ADB 테스트 예정 |
| 실제 GLB 차량 모델 | 합성 GLB 로더 테스트만 있음 |
| 다양한 브라우저 | Chromium 만. Safari/Firefox 미확인 |
| 접근성/성능 장시간 안정성 | 미측정 |

## 실행 방법

```powershell
npm install
npm run typecheck
npm test
npm run build
# 브라우저 통합 테스트: Playwright(chromium)가 설치되어 있어야 함
npx playwright install chromium
node scripts/e2e-smoke.cjs          # dist 를 vite preview 로 띄워 자동 실행, screenshots/ 에 스크린샷 저장
```
