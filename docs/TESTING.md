## 단위 테스트 (vitest, 65개)

- `sensors.test.ts` — 센서 거리 정확도(전/후/좌/우 벽, 0.001m 단위 비교), **차량 회전(90°/180°/-90°/33°) 후 센서 방향**, 지면/낮은 연석/천장 물체 미감지, 자차 미감지, 범위 밖 미감지, 원기둥(콘) 거리, 디버그 광선 정보, 센서 배치(4/4/2/2), 경고음 간격 단조 감소·연속음·무음, 경고 단계, 기어/속도별 경고 대상 그룹.
- `vehicle.test.ts` — 좌표 변환 역변환, P 정지, D/R 가속과 최고속도, 크리프, 제동 후 역주행 없음, 주차 브레이크, **전진/후진 조향 방향**, 조향 복귀, 속도에 따른 조향각 제한, **기어 전환 제한**(주행 중 R/P 거부 등), OBB 겹침, 낮은 연석 비충돌, **최고속도 벽 돌진 시 관통 없음**.
- `parking.test.ts` — **중심점만 안쪽이면 실패, 네 모서리 검사**, 방향 오차(직각 10°/평행 8°), 앞/후진 방향 구분, 평행주차 양방향, 구획 이탈, 회전된 구획, 정차 유지 시간, 움직이면 유지 초기화, 제한 시간 실패, 충돌 감점, 시간 점수.
- `maps.test.ts` — 맵 3종 무결성: 충돌체 id 고유, **모든 차량이 시작 위치에서 겹치지 않음**, 모든 미션 목표 구획이 비어 있고 3종 차량이 규정 자세로 들어갈 수 있음, 주차 차량끼리 겹침 없음.
- `settings.test.ts` — 설정/기록 저장·복원, 손상 JSON 복구, 범위 보정, 저장소 없는 환경에서 예외 없음.
- `glb.test.ts` — 코드로 만든 최소 GLB 를 GLTFLoader 로 읽고 `Wheel_*` 노드를 조향/회전에 연결, 프로시저럴 차체 교체.

## 브라우저 통합 테스트 (Playwright, 67개)

실제 빌드된 페이지를 열어 자동으로 플레이합니다 (스크린샷: `screenshots/`, 대표 컷: `docs/screenshots/`).

- 시작 화면, 맵/차량/설정/조작법 화면 → 게임 진입(HUD)
- P 에서 가속 무반응, F 후 가속 전진, 주행 중 R/P 거부, A 조향 시 좌회전, S 브레이크 정지
- 카메라 5종 순환 (추적→1인칭→탑뷰→후방→자유)
- R 기어 후진, 후방 카메라 보조 화면 자동 표시, 후진 중 조향 방향(뒤쪽이 조향 방향으로 이동)
- 센서: 실제 벽까지 1.00m 일치, 차량 회전 후 방향(북향/남향), 접근 2.2→0.2m 측정값(±0.04m), 낮은 연석 미감지, 센서 화면 크게/숨김/작게 순환, 드래그 회전·휠 줌, 디버그 모드, 센서 OFF/ON
- 충돌/관통: 벽 돌진 → 충돌 카운트, 벽 비관통, 충돌 후 후진 탈출
- 주차: 칸에 걸친 자세 실패, 25° 틀어진 자세 실패, 올바른 자세 + 정차 유지 → 성공 → 결과 화면 → 기록 저장 → 재시도, 실패 화면
- 일시정지(Esc)/재개, 설정 새로고침 후 유지
- 맵 3종 로딩 + 주행, **미션 8개 × 차량 3종 조합 성공 판정**
- 모바일(800×360 가로, 터치 에뮬레이션): 터치 컨트롤 자동 표시, 버튼 크기 ≥ 40px, 화면 D 버튼, 가속 버튼 홀드, 멀티터치(가속+조향), 입력 해제, FPS 표시
- 전체 실행 중 콘솔/페이지 오류 0건

## 검증하지 못한 것 (PASS 로 표시하지 않음)

| 항목 | 이유 / 현재 상태 |
|---|---|
| **APK 빌드/설치/실행** | 개발 세션 네트워크가 `dl.google.com`(Android SDK, Google Maven)을 차단해 로컬에서 Gradle 빌드 불가. 워크플로는 작성했지만 **한 번도 실행되지 않음** → Actions 첫 실행 결과로 확인 필요 |
| 실기기 FPS/발열/터치감 | 휴대폰 없음. 헤드리스 값만 있음 |
| 경고음 실제 청취 | 헤드리스 환경. 간격 계산은 단위 테스트, WebAudio 생성은 오류 없이 동작하는 것만 확인 |
| 배포 환경 경로/리소스 로딩 | `vite preview`(정적 서버)와 상대 경로(`base: './'`) 빌드로 확인. **실제 GitHub Pages 하위 경로 배포는 미실행** |
| 실제 GLB 차량 모델 | 합성 GLB 로더 테스트만 있음 |
| 다양한 브라우저 | Chromium 만. Safari/Firefox 미확인 |
| 접근성/성능 장시간 안정성 | 미측정 |

## 실행 방법

```powershell
npm install
npm run typecheck
npm test
npm run build
# 브라우저 통합 테스트: Playwright(chromium)가 설치되어 있어야 함
npx playwright install chromium
node scripts/e2e-smoke.cjs          # dist 를 vite preview 로 띄워 자동 실행, screenshots/ 에 스크린샷 저장
```
