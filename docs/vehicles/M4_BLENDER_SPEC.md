# M4 계열 쿠페 — Blender 작업 명세 (Codex 인수인계)

게임 내부 차량: `coupe-m4` ("스포츠 쿠페 (M4 계열)"). **현재 외형은 임시 절차 모델**이며 승인된 BMW 에셋은 아직 없다.
공통 규칙: [COMMON_GLB_CONTRACT.md](COMMON_GLB_CONTRACT.md)

## 1. 원본 모델과 라이선스
- 후보(메타데이터만 확인, **파일 미확보**): ① Sketchfab Rosemarin "BMW M4 G82" CC BY 4.0, 104,190 faces, 22 재질, 실내 단순 ② Sketchfab SABLE "BMW M4" CC BY 4.0, 533,906 faces, 30 재질/18 텍스처 ③ BlendSwap #16463 "BMW M4 F82"(G82 아님) CC-BY, .blend 2.07 MB.
- **확정된 원본 없음.** 다운로드는 Sketchfab API 토큰/BlendSwap 로그인이 필요해 받지 못했다(`docs/ASSET_RESEARCH_V041.md`). 파일 확보 후 이 절을 실제 노드 목록/삼각형 수로 갱신할 것.
- 예상 감량: ① 104k→외관 ≤60k(약 40% 감량), ② 534k→≤60k(약 89% 감량, 텍스처 18개 병합 필요).
- 사용자 승인 + 라이선스(재배포·수정 허용, 저작자 표시 방법) 확인 전에는 파일을 저장소에 넣지 않는다. 원본은 별도 보관(저장소 외).

## 2. 작업 범위 (실내 전체 재제작 아님 — 부분 보완)
| 항목 | 작업 |
|---|---|
| 외관 | 로고/배지 제거(메시 + **텍스처 검사**), 한국형 번호판 장착부 수정 |
| 바퀴 | 4개 분리, 피벗=축 중심, 앞바퀴 조향 피벗 |
| 램프 | 헤드/DRL/테일/후진/방향지시 재질 분리 (`Lamp_*`) |
| 실내(기존 모델이 있을 때) | 핸들 회전 피벗, 계기판 영역(`Cabin_Cluster`), 센터 디스플레이(`Cabin_Center`), 공조·기어·버튼 일부 보완 |
| 미러 | `Mirror_L/R/Room` 평면 |
| 최적화 | 모바일 목표 충족 |

## 3. 제원 (게임 기준, `src/vehicle/spec.ts`)
길이 4.794 · 폭 1.887 · 높이 1.393 · 축거 2.857 · 뒷오버행 1.02 · 바퀴 반경 0.34 m. (참고: 실제 G82 M4 는 약 4.79×1.89×1.39 m.)
뒷축 중심이 차량 상태 (x,z). 원점은 차체 중심.

## 4. 카메라/센서/기준점 (차체 중심 기준, +z 앞, +x 왼쪽)
- 1인칭 시점: (x 0.36, y 높이−0.28 = 1.113, z −0.05)
- **후방카메라(유일한 주차 카메라)**: (0, 0.95, −L/2+0.05 = −2.347), 아래로 28°
- 전방카메라: **없음** (`assist.frontCamera=false`)
- 센서 12개: 앞4/뒤4/좌2/우2, 높이 0.55 m, 범퍼 가장자리 (정의: `defaultSensorLayout`). 모델 범퍼에 센서 홀 디테일 가능(게임 판정과 무관).
- 번호판: 앞 y=지상고+0.3, 뒤 동일.

## 5. 게임에 필요한 노드 — 공통 계약 참조 + 쿠페 전용
도어 2개(`Door_L`, `Door_R`), 트렁크 없음(애니메이션 불필요).

## 6. 완료 기준
