## 3. M50i → xDrive40i 외형 변경 점검표 (단순 글자 교체로 완료 처리 금지)
M50i 전용 요소를 모델에서 찾아 40i(M Sport 패키지 기준 여부는 **사양 미확정**)에 맞게 조정:
- 범퍼/하부 디퓨저, 배기구 형태(M50i 는 대형 듀얼, 40i 는 형태/크기 차이 — 정확한 사양은 자료 확인 필요)
- 휠 디자인/크기, 브레이크 캘리퍼 색
- 그릴/외장 장식 색(하이글로스 블랙 ↔ 크롬 등 옵션), 트림 배지(M50i / xDrive40i)
- 실내 장식(M 전용 시트·스티치·계기판 그래픽)
- 불확실한 항목은 `// UNVERIFIED` 로 목록화해 사용자 확인.
