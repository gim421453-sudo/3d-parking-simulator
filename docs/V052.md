## 완료
- **12층 기계식 타워** (`mech/machine.ts`): 2F~12F(층고 3m) × A/B = **22 슬롯**, 슬롯 점유/차량 ID/차종/입고 방향/시각은 `MachineState.slots` 로 장치 상태와 분리. 중복 점유/작동 중 요청/빈 슬롯 출고 거부. 전진 8F A, 후진 12F B 입고 → 실제 높이(21m/33m)까지 승강 → 보관(브라우저 검증, 스크린샷).
- **캐리지/팔레트 분리**: 입고하면 팔레트+차량이 슬롯에 남고 **빈 캐리지가 1F 로 복귀**, 승강장에 새 빈 팔레트 공급, 문 열림 → 다음 입고. 출고는 빈 캐리지가 올라가 팔레트+차량을 인출해 하강.
- **4개 모서리 기둥 + 수직 가이드 레일 + 층별 슬롯 레일/보**, 팔레트 중앙(차량 보관 공간) 기둥 없음(E2E 로 기둥 좌표 검증).
- **전진/후진 정렬 분리**: 전진은 앞차축, 후진은 뒷차축 기준(`alignment` 모드별), 표시기 방향/좌우 힌트도 모드별(후진 입고에서 "후진" = 계속 후진, 지나치면 "전진").
- **출고 회전 분기**: 전진 입고 차량은 180° 턴테이블 후 문을 향함, 후진 입고 차량은 회전 없음(중복 회전 금지). 비상정지/재개.
- **안내 장치**: 거울 바로 옆 전진/정지/후진 표시판(실제 위치 기반), 셔터 상단 정중앙 **별도** 작동 상태 LED(입고 가능/입고 중 — 08F 이동/승강 중/플랫폼 복귀 중/출고 중 — 12F 차량 호출/입출고 금지/비상 정지/고장), 셔터 옆 제어반(3D 함체) + HUD 제어반 모달(Z 키): 층/슬롯 선택(점유 표시), 입고/출고/취소/비상정지·해제, 자동/수동 슬롯 선택(설정 저장).
- **물리**: 팔레트 가이드 0.12m(지상고 0.2m 아래, 타이어가 타고 넘음 + 경고/저항), 정지턱은 약한 저항(0.25m/s²)만 — 더 이상 차량을 밀어내거나 0 으로 고정하지 않음, 낮은 정지턱 위 안착 홈(전진 앞차축/후진 뒷차축, 3cm, 효과음), 기계식 맵에서 접촉면 미끄러짐 + 감쇠.
- **자유시점 카메라 y 추적** 버그 수정(12층까지 상승하는 차량을 놓치던 문제).
- **통합 맵 `megapark`**: 기존 9개 구역을 하나의 장면에 배치(`maps/compose.ts` 평행이동 + ID 네임스페이스), 서쪽 간선도로 + 구역 진입로(지하주차장은 동쪽 입구 → 북쪽 우회 도로), 모든 구역 도착 주행 시뮬레이션(세단/SUV) 충돌 0, 미션 59개(기계식 전진/후진/8F/12F 입고·출고 포함), 거리 기반 주차 차량 컬링.
- 기존 9개 맵은 개별 선택 유지(맵 10개).

## 부분 / 제한
- 통합 맵: **기계식 장치 좌표가 절대값(`STATION`)** 이라 기계식 구역은 원점에 고정(장치 인스턴스화/다중 설치는 미구현). 지하주차장 "출입 경사로"는 만들지 않고 지상 높이의 실내형 구역으로 연결. 구역별 LOD/지연 로딩은 없고 주차 차량 거리 컬링만. 전체 맵 내비는 "경로 없음"(noRoute). **렌더 성능/메모리는 측정하지 못했다.**
- 볼라드: 정면 접촉 = 관통 불가 + 후진 이탈(E2E). 접촉면을 따라 미끄러지는 처리는 코드에 있으나 E2E 로는 검증하지 못했다.
- 입고된 차량 모델은 슬롯 위에 그대로 렌더(22대까지 최악 비용 미측정).
- 출고 시 현재 플레이어 차량(대기 중인 새 차)은 인출된 차량으로 **교체**된다(이전 차는 사라짐).
- 통합 맵/12층 타워 모바일 가로 화면 확인 없음.
