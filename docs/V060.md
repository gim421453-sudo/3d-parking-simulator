## 충돌 파손 물리

외부 물리 엔진 라이브러리는 쓰지 않았다. 차량 주행 물리(자전거 모델 + 1/120s 스텝 + 서브스텝)가 이미 직접 만든 코드이고 1,000개가 넘는 테스트가 그 동작에 묶여 있어서, 강체 엔진으로 바꾸면 주차 감각과 검증이 모두 바뀐다. 대신 **충돌 순간을 물리 법칙(운동량 보존·반발계수·운동에너지)으로 계산하는 모듈**을 붙였다.

- `physics/impact.ts` (순수 로직)
  - 접촉 법선 n(장애물 표면 → 차체 중심), 접근 속도 vn = −(V_rel · n). 비스듬히 스치면 vn 이 작아 손상도 작다.
  - 에너지 E = ½ μ vn² (μ: 움직이는 물체는 환산 질량 m1·m2/(m1+m2), 고정 물체는 차량 질량).
  - 재질표(태그·크기): 콘 4kg·드럼 30kg·주차 차량 1.4t = **밀림**(충격량 J=(1+e)μvn 주고받음), 화분·집기·방호벽 = **산산조각**(부피 비례 내구도), 가로등·나무·볼라드 = **넘어짐**, 벽 = **구멍**(두께·높이 비례 내구도 — 0.3m×1.2m 벽 250kJ ≈ 세단 시속 66km), 건물·기둥 = **균열만**(사라지지 않음), 기계식 셔터·리프트 기둥·가이드 = 파손 대상 아님.
  - 손상은 누적된다(같은 벽을 여러 번 들이받으면 낮은 속도로도 부서짐).
  - 부서지면 장애물이 버틴 에너지만큼 차량 속도가 줄고 통과, 버티면 막히고 시속 9km 이상 정면 충돌은 살짝 튕긴다(반발계수). 그보다 느린 접촉은 이전과 같이 그 자리에 멈춘다(주차 감각 유지).
  - 차량 질량은 차체 부피 근사(세단 ≈ 1.5t).
- 내 차 손상: 2kJ(≈시속 6km) 미만은 범퍼가 흡수, 한 부위 100% = 210kJ(≈시속 60km 정면). 30% 까지 성능 영향 없음, 그 위로 출력/최고속도 감소, 앞 40% 이상 전조등 파손, 55% 이상 연기, 측면 40% 이상 그쪽으로 쏠림, 100% 면 엔진 정지·시동 불가(다시 시작 T). 외형: 손상된 끝이 짧아지고 기울어짐(**시각만** — 충돌 상자/센서 좌표는 그대로).
- `physics/bodies.ts`: 밀린 물체의 마찰 감속·벽 반발(관통 없음). `physics/debris.ts`: 파편·불꽃·연기 입자(시각 전용, 충돌체 아님).
- `fx/damageWorld.ts`: 결과를 월드에 적용 — 충돌체 제거/벽 조각 분할/동적 목록, 피벗 이동·쓰러짐·찌그러짐, 균열 자국, 입자 렌더링. 맵 빌더 `extract(id)` 로 합친 메시·인스턴스에서도 그 물체만 떼어 낸다. **그리지 못하는 물체(예: 기계식 시설 모델이 그리는 볼라드)는 제거하지 않는다** — 보이는 것과 충돌체가 어긋나지 않게.
- `vehicle/worldStep.ts`: `impact` 콜백(게임 전용). 헤드리스 맵 검사(autodrive/planner)는 콜백 없이 이전 동작 그대로.
- 재시작(T): 무언가 부서지거나 밀렸으면 맵을 다시 만든다(원래 상태). 내 차 손상도 초기화.
- 계기판: 미니 차량에 부위별 손상 색(숫자 없음), "손상" 경고등, 심한 손상/운행 불가 문구.

브라우저 측정(e2e-v060, 세단): 콘 시속 30km → 튕겨 나감·손상 0 / 주차 차량 시속 20km → 밀림·내 차 앞 5% / 벽 시속 30km → 막힘·균열·앞 28% / 벽(0.6m) 시속 100km → 구멍·통과·운행 불가 / 방호벽 시속 50km → 부서짐.

## 괴정동 실제 지도

- 범위: **괴정역(35.09975 N, 128.99159 E) 중심 1km×1km**. 괴정동 법정동 중심점(35.10496, 128.99700)은 동주대 쪽 언덕이라 괴정역이 범위 밖이 되어, 대표 지점인 괴정역을 중심으로 했다. 다른 중심을 원하면 `scripts/osm-import.ts` 를 다시 실행하면 된다.
- 데이터: OpenStreetMap API(2026-11-14). 도로 105개(낙동대로·괴정로·사하로·승학로 등, 차량 통행 등급만), OSM 건물 67동(층수→높이), 주차장/녹지/운동장 면, 도로망 그래프 356노드(95% 이상 하나로 연결).
- **OSM 에 건물이 등록되지 않은 블록은 절차 생성 건물 520동(2~5층)으로 채웠다 — 실제 건물이 아니다.** 데이터에 `gen: 1` 로 구분, 미니맵에서 어두운 색.
- 고도(언덕) 미반영 — 평면. 주차칸은 OSM 주차장 면 안에 자동 배치(임시), 기계식 주차타워(낙동대로 남쪽 빈 터)도 임시 배치.
- 렌더링: `maps/geoBuilder.ts` — 도로 리본, 건물 다각형 돌출(창문 텍스처·건물별 색), 면. 48m 타일별로 합쳐 먼 타일은 숨긴다(구역이 없는 대형 맵에도 스트리밍 적용).
- 충돌: `world/footprint.ts` — 건물 다각형을 1m 격자로 래스터화해 회전 상자 여러 개로(ㄱ자 건물도 모양을 따라감, 오차 ±0.5m).
- 내비: `nav/roadNet.ts` — 실제 도로 중심선 A*(일방통행 반영). 1km 지도에서 격자 탐색은 너무 무거워 쓰지 않는다.
- 라이선스: ODbL 1.0 — `src/maps/data/LICENSE-OSM.md`, `docs/ASSETS.md`, 맵 설명·미니맵에 "© OpenStreetMap contributors".
- 미션: 괴정역 → 사하도서관 주차장(실제 도로망 안내), 괴정역 기계식 주차타워 입고.

## 알려진 제한 / 남은 일

- 외부 물리 엔진 미사용(위 이유). 파편끼리/파편과 차의 충돌은 없음(시각 전용). 밀린 물체끼리는 서로 막기만 한다(운동량 전달 없음).
- 건물·기둥은 사라지지 않는다(균열·파편만) — 건물 안이 비어 있지 않은 단순 상자라서 "뚫린 건물"을 표현할 수 없다.
- 벽 조각을 다시 들이받으면 그 조각에 새 구멍이 난다(누적 손상은 조각마다 새로).
- 괴정동: 고도 미반영, 건물 대부분 생성(OSM 미등록), 주차칸/기계식 위치는 임시, 횡단보도·신호등·보도 턱 없음.
- 소프트웨어 WebGL 측정 FPS 는 실기기와 무관.
