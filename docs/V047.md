## 2. 정차 중 핸들 유지
`core/wheel.ts` `WheelModel.update` 가 속도와 무관하게 중앙 복귀하던 것이 원인. 이제 **실제 차량 속도**(`|v|`)로 판정: 0.15 m/s 미만이면 `holding`(복귀 금지), 0.35 m/s 초과 시 해제(히스테리시스). 기어 P 여부와 무관(D/R 브레이크 정지 포함). 핸들 각도 → `steerInput` → `VehicleState.steer` → 앞바퀴/예측선이 모두 같은 값을 쓰므로 표시만 고정되는 일 없음(E2E 에서 HUD/steer/steerInput/바퀴 모델/예측선 확인). 키보드 조향은 기존 동작(램프)이다.

## 3. 오른쪽 PDC 화면: 3D 서라운드 ↔ 센서 전용
- 설정 `pdcView: 'surround'|'sensor'`(저장/복원). `Action 'pdcSurround'|'pdcSensor'` — 3인칭 패널 `.pa-mode` 버튼, 1인칭 실내 화면 터치 영역이 같은 경로.
- 서라운드 미지원 차량(M4)은 `data-surround-supported=false` → 버튼 숨김, 요청 무시.
- 센서 모드에서는 서라운드 3D 렌더 중지, 전환 시 서라운드 캔버스/경고선 보간 상태 초기화. 왼쪽 메인 카메라(수동/자동)는 건드리지 않는다.

## 4. 서라운드 예측 거리선
`pdc/guidelines.ts` 의 `buildGuideLines`(마크 거리 `SURROUND_MARKS` = 0.5/1/2/3m)와 `guideCutDistance` 를 메인 카메라와 **같이** 사용 → 두 화면이 서로 다른 경로를 그릴 수 없다. D=앞, R=뒤, 정차 중 조향 반영, 장애물 직전 절단, 다층은 `groundAt` 높이. 거리 숫자는 쓰지 않음(규칙 11). 선 두께/가로 눈금으로 PDC 경고선(외곽, 굵음)과 구분. 서라운드/집중 탑뷰에는 어두운 차체가 바닥에 묻히지 않도록 차량 외곽선(진행 방향 범퍼 강조)을 그린다. 서라운드 카메라 범위는 범퍼 너머 3.5m.

## 5. 전방/후방 집중 탑뷰에서 자기 차량이 안 보임
- 확정 원인(재현·테스트): 장애물이 멀리(≈6m) 있으면 프레임이 장애물을 포함하려다 높이 상한(12m)에 걸려 **자기 차량 범퍼가 화면 밖**으로 밀렸다 (`tests/focusTop.test.ts` 가 수정 전 12건 실패). 수정: 차량의 해당 방향 40%를 항상 우선 포함하고 장애물은 가까운 것부터 상한 안에서 가능한 만큼만 추가.
- 보조 원인(추정 → 시각 확인): 검은 차체가 어두운 아스팔트에 묻힘 → 외곽선/범퍼선 오버레이.

## 6. 후방/전방 카메라가 속도에 따라 움직임
- 확정 원인: `CameraRig.updateAssistCamera` 가 프레임이 없는 시점(후방/전방)에서도 매 프레임 지수 보간(`k=1-exp(-7dt)`) → 카메라가 차체보다 **v/7 m** 늦게 따라와 영상 속 범퍼/차체가 속도에 비례해 이동. 측정(수정 전, 단위 시뮬레이션): 1km/h 3.7cm, 3km/h 11.2cm, 5km/h 18.7cm, 10km/h 37.4cm (`docs/screenshots/v047/rear-camera-lag-before.txt`).
- 수정: 후방/전방은 전환 후 0.45초 뒤 보간 없이 차체에 고정(`rigid`). 또한 장착 자세를 `mountedCamera()` 로 차량 모델 root 와 같은 변환(YXZ heading/-pitch)으로 계산해 경사로 피치에서도 어긋나지 않게 함(메인 후방/전방 카메라 포함).
- 수정 후: 실제 게임 루프 E2E(0/1/3/5km/h, 전·후방) 에서 차체 로컬 좌표 편차 0.00mm.
- 남은 가능성: 실기기 렌더 지연/프레임 드롭으로 인한 시각적 끊김은 측정하지 못했다.
