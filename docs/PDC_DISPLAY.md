# 주차 보조 디스플레이 (PDC + 후방/전방 카메라)

차량 인포테인먼트 스타일의 주차 보조 화면입니다. BMW iDrive 7 의 "카메라 + 차량 센서 시각화 + 우측 고정 사이드 메뉴" 배치와 iDrive 8.5 의 어두운 와이드 분위기를 **참고**했고, 로고·이미지·글꼴·그래픽은 사용하지 않은 독자 구현입니다. (iDrive 8.5 의 큰 타일 메뉴는 쓰지 않음)

## 구성 (고정 레이아웃)

```
┌ 주차 보조  [R]  후방 카메라                                   [×] ┐
├──────────────────────────┬───────────────┬──────────────────────┤
│ 카메라 영상 (3D 장면)     │ 차량 탑뷰 PDC │ 주차 보조      켜짐   │
│  + 조향 연동 가이드라인   │  (센서 구역)   │ 경고음         켜짐   │
│                          │ 상태 문구      │ 카메라 화면    자동   │
│                          │               │ 설정                  │
└──────────────────────────┴───────────────┴──────────────────────┘
```
- 사이드 버튼 4개는 항상 같은 자리에 있습니다. R↔D, 카메라 변경, 센서 OFF 에서도 DOM 이 재생성되지 않고 위치가 변하지 않습니다(E2E 에서 DOM 노드 동일성과 좌표 일치를 검증).
- **서라운드뷰는 아직 없습니다.** 360° 버튼/영상/가짜 장애물은 만들지 않았습니다. 추후 구현되면 PDC 탑뷰 영역을 교체하고 사이드 메뉴 위치는 유지합니다.

## 카메라와 PDC 는 실제 게임 데이터

- 카메라 영상: 같은 Three.js 장면을 후방/전방 카메라로 다시 렌더링해 패널 캔버스에 복사합니다. 정적 이미지·가짜 영상 없음. 갱신 속도는 설정(`주차 보조 카메라 갱신 속도`)으로 조절합니다.
- PDC 구역: 센서 12개의 충돌체 레이캐스트 결과 → 단계(far/mid/near/critical/none). 센서 장착 위치의 극각으로 차 주변 360°를 12구역으로 나누고, 구역마다 4개 띠가 **바깥→안쪽**으로 채워집니다(안쪽일수록 위험). 미검출 구역은 소등되어 거짓 경고가 없습니다.
- **일반 화면에는 거리(m) 숫자를 표시하지 않습니다.** 방향·구역·색·경고음 간격·단계 문구만 보입니다. 숫자는 설정의 "센서 디버그 모드"에서만 나옵니다. (`src/pdc/pdcModel.ts` 의 출력에는 거리 필드가 없음 — 단위 테스트로 고정)
- 색상 단계: 초록(여유) → 노랑(접근) → 주황(근접) → 빨강(매우 근접 + 연속 경고음). 팔레트 3종(표준/색약 친화/고대비)을 설정에서 선택.
- 동적 가이드라인: `src/pdc/guidelines.ts` 가 저속 자전거 모델과 같은 기구학으로 차체 좌/우 끝선의 예상 경로를 계산하고(단위 테스트에서 실제 `stepVehicle` 궤적과 일치 확인), 실제 카메라 투영으로 영상 위에 그립니다. 거리 구간별 빨강→노랑→초록.

## 표시 정책 (`src/pdc/assistPolicy.ts`)

| 상황 | 동작 |
|---|---|
| **R 선택** | 주차 보조 자동 표시: 후방카메라 + 후방 PDC (설정 `R 자동 표시` OFF 면 열지 않음) |
| **D 선택** (속도 ≤ 설정값, 기본 10km/h) | 같은 화면에서 **카메라만 전방으로** 전환 + 전방 PDC |
| D 에서 속도 > 설정값 | 자동 종료(일반 화면 복귀). 설정값×0.6 이하로 느려지면 다시 표시(히스테리시스) |
| **N** | 표시 중이고 저속이면 유지, 고속이면 종료 |
| **P** | 설정 지연(기본 3초) 후 종료 |
| 수동 우선 | `카메라 화면` 버튼(자동→후방→전방): 다음 기어 변경 시 자동으로 복귀. `×` 닫기: 다음 기어 변경까지 다시 열리지 않음. `B`/액션바 버튼: P 에서도 수동 열기 |
| 센서/경고음 OFF | 설정 존중: R 에서도 센서를 강제로 켜지 않음. 패널에 "PDC 꺼짐" 표시 |

경고음 대상: R = 후방+측면, D 저속(10km/h 미만) = 전방+측면 (`sensors/sensorSystem.ts#activeGroupsFor`).

## 조명 (`src/vehicle/lighting.ts`)

L 키 / 액션바 버튼으로 OFF → 미등 → 하향등 → 상향등 → AUTO 순환.
OFF: DRL 100%(P 제외) · 미등: DRL 100% + 후미등 · 하향등: DRL 30% + 하향등 · 상향등: DRL 30% + 하향 + 상향 · AUTO: 어두운 맵(지하)에서 하향등.
하향/상향은 실제 SpotLight 로 노면·벽·장애물을 비춥니다. **AUTO Leveling** 은 서스펜션/피치 물리가 없어 **가속도 기반 근사**입니다(가속 → 빔 아래, 제동 → 위, 데드밴드·1차 지연·±2° 제한).
**오토 상향등(Auto High Beam)은 미구현** — 맵에 이동 차량/대향차 감지 로직이 없어 완성된 것처럼 표시하지 않았습니다. AFS 는 후속(조향각 → 좌우 조사 방향) 과제입니다.
