### 알려진 차이 (실제 지도 ↔ 게임)
- OSM 건물 등록이 실제보다 적다(빈 블록). 국토부 건물정보는 외부 차단.
- 건물 외벽·창문은 실제 모습이 아니다(공용 텍스처). 높이 82%는 추정.
- 차로 수 96%가 추정, 좌·우회전 전용 차로(turn:lanes 2개 way)·버스전용차로·정지선·횡단보도·방향 화살표는 그리지 않는다.
- 지형은 DSM 가공 추정: 열림(반경 100m)이 폭 200m 미만 봉우리를 깎는다. 숲 지역 서비스 도로 최대 경사 77%처럼 과대 추정이 남아 있다(경사 20% 초과 도로 길이 4.6%, 25% 초과 2.2%).
- 교량 종단은 양 끝 지면을 잇는 직선 + 입체 교차면 최대 5.5m 올림(실제 설계 종단 아님). 터널은 지형을 비워 위에서 보인다.
- 다대동 남쪽 섬은 경계에 포함되지만 도로가 없다.
- 시작 지점 높이 기준(y=0)은 괴정역 기계식 시설 자리(해수면 = y −45.0, DEM 기준 해발 약 45m — 추정 지표면 값).

## 구현 (Gate A~C)

- `scripts/saha/fetch-osm.ts`: 경계 상자 격자만 수집, 실패 시 4분할, 중간 결과 보존(이미 받은 파일 건너뜀).
- `scripts/saha/lib/tm.ts`: EPSG:5186(GRS80 TM) 정/역변환(왕복 오차 0). 게임 좌표 = 괴정역 원점 미터, +x 동, +z 남.
- `scripts/saha/lib/dem.ts`: COG 창 읽기 + 쌍선형 표본, **타일 이음매(경도 129.0°) 보정**(빈 값 → 0 → 바다 오인으로 급경사 띠가 생겼다).
- `scripts/saha/build.ts`: 경계 멀티폴리곤, 도로(일방 −1 정규화·로터리·통행 금지 제외·경계 150m 완충·8m 조밀화·노면 높이), 차로(OSM/추정 구분), 회전 제한, 건물(멀티폴리곤 구멍·중복 제거·용도별 추정 층수), 주차장, 토지피복 래스터, 추정 지표면(열림 100m + 가우시안), 시설 자리 평탄화, 바다, 240m 타일, 품질 보고, `LICENSE.md`.
- `src/maps/terrain.ts` `HeightField`/`fieldHeight`: 렌더 메시와 **같은 삼각형 분할** 보간 → `groundAt` 후보.
- `src/maps/saha/data.ts`/`mapSaha.ts`: 로더, 상판 → ramp 면, 메뉴용 자리표시(`stream.ready=false`) → 데이터로 만든 MapData(낙동대로 출발·하단/다대포 미션·괴정역 기계식 시설 같은 자리), `buildingColliders`(기초 6m).
- `src/world/sahaStream.ts`: 반경(화질 low 300/medium 400/high 520m) 안 타일만 지형·도로(꼭짓점마다 지형 높이에 붙임)·차선·건물·주차장·교량/터널 + 건물 충돌체 push/splice(배열 참조 유지), 먼 지형·바다 상시.
- `Game`: 비동기 로딩 후 시작, 원거리 평면 3km·안개, 미니맵 경계·도로망, `surfaceMu`(도로 = 아스팔트, 도로 밖 = 토지피복 마찰), `groundHeight`(디버그).
- `nav/roadNet.ts`: 회전 제한(근사 A* — 노드별 직전 노드 하나), 간선 격자 색인(64m).

## 핸들링 (Gate D)

구조: ≤3m/s 는 **이전과 똑같은 기구학 자전거 모델**(주차·기존 검사 보존), ≥6m/s 는 동역학 단일 궤도 모델, 사이는 혼합(`vehicle/handling.ts`).
- 상태 추가: `vy`(무게중심 횡속도), `yawRate`, `ay`, `grip`(접지 사용률).
- 타이어: 코너링 강성 = 단위 하중당 계수 × 축 하중, `tanh` 포화, 가감속 하중 이동, 마찰원, 미끄러짐 감속(vy·r − Fyf·sinδ/m).
- **한계 언더스티어**: 앞 접지 한계 0.9 배. 앞·뒤 한계가 같으면 둘 다 포화될 때 요 모멘트가 0 이 되어 약한 감속에도 스핀했다(개발 중 발견, 회귀 테스트).
- **ESC 근사**: 조향 요구 요 레이트를 넘는 과회전·횡미끄럼 7° 초과만 줄인다(언더스티어에는 개입 안 함). 선회 중 급제동 스핀(뒤 하중 감소)을 막는다.
- 제동 감속 = min(7.5, 0.95·μ·g). 오르막 저속 구동력 증배(1단·토크컨버터 근사, 오르막 부하일 때만 — 평지 가속 동일). 30% 경사 출발 가능.
- 노면 μ 표(`SURFACE_MU`: 아스팔트 1, 콘크리트 0.92, 비포장 0.6, 풀 0.45, 젖은 아스팔트 0.7(후속)).
- 손상 연동: `carDamageEffects.grip`(옆·앞 40% 초과 손상부터 최대 −40%) × 노면 μ → `VehicleInput.mu`, 기존 조향 쏠림(`steerPull`)·출력/최고속도 제한·운행 불가 그대로.
- 차종별 질량/무게 배분/무게중심/타이어 계수는 **모두 추정값**(`handlingOf().estimated`). M4/X6 프로필은 실제 제원이라고 표기하지 않는다. 손상 계산용 질량(`vehicleMassKg`, 부피 근사)과는 아직 별개.

## 버그 기록 (원인 · 수정 · 재발 방지)
1. **DEM 타일 이음매 빈 값** — 경도 129.0° 픽셀 중심 사이 점이 NaN → 0 → 바다 처리 → 1,749% 경사 · 가장자리 픽셀 고정 · 품질 보고 `missingCells` 0 확인.
2. **도로 조각 경계 점 공유** — 타일 조각이 같은 점 배열을 공유해 기준고를 두 번 뺌 · 조각마다 점 복사 · `tests/saha.test.ts` 도로 높이 = 지형 검사.
3. **도로가 지형에 묻힘** — 8m 간격 데이터 점을 직선으로 잇는 리본이 20m 지형 삼각형 꺾임 아래로 · 렌더 시 2m 분할 + 꼭짓점마다 지형 높이 · 브라우저 화면 확인.
4. **고속 풀조향 스핀** — 앞·뒤 동시 포화 시 요 모멘트 0 + 미끄러짐 감속 없음 · 앞 접지 0.9, 미끄러짐 감속, ESC 근사 · `tests/handling.test.ts` 스핀 회귀.
5. **y=0 아래 물체 통과(사하구 저지대 건물 + 통합 맵 지하 B1, v0.5.4~)** — `findVehicleCollision` 이 높이 구간 검사 전에 절대 높이 0.2m 로 낮은 물체를 걸렀다 · 높이 정보가 있으면 차량 기준 검사만, `levelGraph` 도 층 기준 · `tests/geometry.test.ts`(수정 전 실패 확인).
6. **경사지 건물 밑 통과** — 건물 바닥 = 외곽 꼭짓점 최저 지면이라 낮은 쪽에서 오면 충돌체 아래 · 기초 6m(`BUILDING_FOUNDATION`) · `tests/saha.test.ts` 회귀(수정 전 실패 확인).
7. **mech/recovery 순환 import** — 최상위 `void SLOTS` 가 CJS 로드 순서에 따라 TDZ 오류 · 제거.
